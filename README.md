# genie_pdf

지니뮤직 UX/UI 케이스 스터디 — PDF 제출용 16:9(1920×1080) 슬라이드 웹페이지.

- 인터랙티브 원본: https://portfolio-geniemusic.vercel.app/
- 원본 소스: https://github.com/jeongwoo-pjw/Portfolio_genie

## 로컬 미리보기

```bash
python -m http.server 5600
# http://localhost:5600
```

빌드 단계 없음 — `index.html` + `styles.css` + `scale.js`(슬라이드 비율 유지 스케일링), 이미지는 `assets/img/`.
