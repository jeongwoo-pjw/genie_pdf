06 / 11 AS-IS / TO-BE · Navigation

홈 · 내비게이션 — 지니뮤직에서만 제공하는 차별화 기능을 손쉽게

PROBLEM
  • 필요도가 적은 GNB 구성 (이용권·프로필 아이콘)
  • 차별화 기능에 접근하려면 여러 프로세스를 거쳐야 함
  • 음악 탐색 메뉴임을 알기 힘든 ‘홈’ 탭 이름

AS-IS

메인화면

1 2
  1. 1

    강점 없는 GNB이미 이용권을 구독 중인 다수 사용자에게 이용권 아이콘은 불필요한 UI

  2. 2

    강점이 보이지 않는 탭바홈 · 오디오 · 검색 · 내음악 · 전체메뉴 — 차별화 ‘기능성’ 메뉴 부재

TO-BE

차별화 기능 노출 · ON / OFF 두 가지 상태

  1. 1

    GNB 토글이용권·MY 삭제, 돌비 애트모스 / 굿나잇 뮤직 on/off

  2. 2

    장르 칩콘셉추얼한 구분을 장르별로, 오디오를 메인 컬럼에

  3. 3

    탭바‘홈’→‘뮤직’, 뮤직허그 탭 배치

Design Decision

  1. 기능 발견 가능성기능을 메뉴 깊숙이가 아닌 GNB에

    전체메뉴 속 작은 글씨 대신, 매번 보는 상단 바에서 바로 켜고 끔

  2. 명확한 상태 구분아이콘 명도로 ON / OFF 표현

    별도 설정 화면 없이 현재 상태를 아이콘만으로 확인

  3. 조작 부담 최소화탭 이름이 곧 역할

    ‘뮤직’ 아이콘·명칭으로 음악 탐색 메뉴임을 전달, 소통 창구 뮤직허그를 1탭 거리로

연관추천 진입 — 리스닝 중, 상단 스와이프만으로 추천 리스트까지

PROBLEM
  • ‘유사곡 리스트’라는 목표에 도달하기까지 시간 지연
  • 리스트 전 카테고리를 오버스크롤로 한 번 더 터치해야 하는 불필요한 과정

③ 카테고리 탭 → ④ 리스트

경로상단 스와이프 → 바텀시트 오버스크롤 → 탭 → 추천 리스트4단계

TO-BE

기본 상태 → 사용자 행동 → 결과

→ →

경로상단 스와이프 → 추천 리스트 확인2단계 (설계 경로 기준)

Design Decision

  1. 조작 부담 최소화중간 단계를 없애고 제스처 하나로

    곡 재생 하단을 위로 스와이프하면 바로 추천 리스트 화면으로 전환

  2. 기능 발견 가능성‘연관 추천 ⌃’ 진입점 유지

    기존 사용자가 알던 위치·라벨을 그대로 두어 학습 비용 없이 경로만 단축

  3. 청취 맥락 유지리스트 하단에 현재 곡 미니 플레이어

    추천을 둘러보는 동안에도 듣던 곡의 재생 상태를 확인

단계 수는 화면 설계상 경로 비교이며, 실제 탐색 시간 단축은 검증 전입니다.

Design Decision

  1. 청취 맥락 유지미리듣기를 독립된 창으로 분리

    재생목록을 바꾸지 않고 카드 안에서만 들어보므로, 닫으면 듣던 곡으로 복귀

  2. 조작 부담 최소화좌우 스와이프 하나로 두 가지 탐색

    카테고리 전환과 다음 곡 탐색을 같은 제스처로

  3. 기능 발견 가능성GUI로 부가정보를 한눈에

    앨범 이미지·발매일·좋아요·댓글 수와 공유하기 / 담기 버튼을 카드에 직접 노출

재생목록 편집 — 편집에만 집중할 수 있게

PROBLEM
  • 과정을 인식하기 힘든 재생목록 편집 UI
  • 편집 시 떨어지는 정보 인식으로 편집이 어려움
  • 곡을 하나씩 옮겨야 하는 편집 방식

AS-IS

재생목록 화면

  1. 1

    ‘재생 | 편집’ 구분이 약함작은 텍스트로만 모드를 표시

  2. 2

    선택 상태 인식이 어려움얇은 원형 체크박스, 선택 행의 대비가 낮음

  3. 3

    한 곡씩 이동행마다 드래그 핸들로 순서를 옮겨야 함

TO-BE

기본 상태 → 사용자 행동 → 결과

→ →

편집 모드탭하면 선택만, 재생에는 영향 없음 · 하단 액션바에 선택 개수 배지다중 곡 편집

Design Decision

  1. 명확한 상태 구분재생과 편집을 모드로 분리

    편집 모드에서는 곡을 탭해도 선택만 가능, 곡 재생에는 영향을 주지 않음

  2. 명확한 상태 구분선택된 곡을 시각적으로 강조

    채워진 블루 체크 + 행 배경 하이라이트, 하단 바에 선택 개수 표시

  3. 조작 부담 최소화드래그로 여러 곡을 한 번에

    한 곡씩 옮기던 방식에서 다수 곡 일괄 이동·삭제·담기로
